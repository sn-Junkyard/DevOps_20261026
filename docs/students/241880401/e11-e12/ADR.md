# ADR：适配可配置的测试宏

状态：已实施。课程验证器固定把 config.h 写为 `#define VALUE 2`，无法验证小游戏使用的 `TARGET`，而直接覆盖整个文件会丢失其他宏。选择为验证器增加可选 `value_macro`，默认 VALUE；仅替换原先值为 1 的指定宏为 2，保留其余内容。宏名不合法或定义缺失/重复时拒绝补丁，原 Makefile 不变。E12 请求用 `validation_macro: TARGET`；旧请求不传参数时保持课程默认行为。自动测试覆盖替代宏、其他宏保留及缺失时回滚。保留课程限定的目标、程序 1→2 和显式 Make 规则，不把它描述为通用适配。
