# ADR 与 AI 使用

- 决策：E13 报告交接在接收端按请求中给定的 SHA256 验证文件字节；原有不提供 SHA 的调用继续兼容。报告自身目标提交和类型仍需验证。
- 决策：四服务请求沿用 E11—E12 的 `validation_macro` 可选字段，缺省 VALUE；小游戏显式使用 TARGET，不改变其他调用的默认行为。
- 决策：四服务只将经工作目录边界检查的项目快照配置为容器内 Git 安全目录，避免跨用户挂载的 Git 安全检查造成误报。
- 限制：信封内的 A 来源哈希可记录，但接收的文件没有附带原始 A 报告，不能独立重算原始报告哈希。
- AI 使用：使用 OpenAI Codex 辅助阅读材料、编写适配、执行测试和整理报告；运行结果和日志来自实际执行。参考实现与个人改动在个人报告中区分。
